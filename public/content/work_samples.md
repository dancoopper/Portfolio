# Process.Work_Samples

### [01] Zector
- **Stack**: FastAPI, Go, ChromaDB, Python
- **Source**: [https://github.com/sokmontrey/zector](https://github.com/sokmontrey/zector)
- Engineered a high-performance vector database client-server architecture using efficient data embedding and retrieval workflows.

### [02] Hacker Tracker
- **Stack**: React, Node.js, MongoDB
- **Source**: [https://github.com/dancoopper/Hacker-Tracker](https://github.com/dancoopper/Hacker-Tracker)
- QR code check-in system for hackathon attendees. Scan a hacker's QR code (encoding their UUID), validate it against the registered attendee list, and log the check-in.

### [03] Visionr
- **Stack**: Python, WebSocket, HTML, CSS, JavaScript
- **Source**: [https://github.com/omelettech/visionr-hackville](https://github.com/omelettech/visionr-hackville)
- A computer vision engine using OpenCV library to translate real-time visual data into spatial audio cues.

### [04] PonkoV2
- **Stack**: 100% Go
- **Source**: [https://github.com/dancoopper/ponkoV2](https://github.com/dancoopper/ponkoV2)
- A small desktop app to get the nasa picture of the day. It also has a feature to save your favorite pictures and view them later. (remake of an older python project)

### [05] Hacker.Portfolio
- **Stack**: React, TailwindCSS
- **Source**: [https://github.com/dancoopper/Portfolio](https://github.com/dancoopper/Portfolio)
- The application you are currently viewing. A dynamic markdown-driven SPA.
